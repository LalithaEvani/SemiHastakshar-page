# SemiHastakshar — Project Page

Project page for the ICVGIP 2025 paper *"SemiHastakshar: Generalizable Indic
Handwritten OCR through Semi-Supervised Learning"* (Lalitha Evani, Ajoy
Mondal, Jawahar C. V. — IIIT Hyderabad).

- **Live page:** https://LalithaEvani.github.io/SemiHastakshar-page/
- **Paper (ACM DL):** https://doi.org/10.1145/3774521.3774605
- **Code:** https://github.com/LalithaEvani/SemiHastakshar

The paper is CC BY 4.0, so a copy is self-hosted at `static/pdfs/paper.pdf`
and served via the template's built-in PDF viewer.

## Editing

Everything is in `index.html` — no build step. Figures are in
`static/images/`, pulled directly from the published paper.

## Deploying changes

```
git add -A && git commit -m "..." && git push
```
GitHub Pages serves straight from `main` — no separate build/deploy workflow.
